<Title>Zotly Chat Widget — Design System</Title>

<Subtitle>An atomic design system for the chat widget, built with Lit web components.</Subtitle>

This Storybook documents the widget's component library, organised using **atomic design**:
a strict one-way hierarchy from tiny atoms up to the single smart template that wires them together.

<Heading as="h2">The hierarchy</Heading>

- **Atoms** — the smallest building blocks (icon, avatar, badge, status ticks…). No business logic.
- **Molecules** — groups of atoms that form a meaningful UI unit (composer, message bubble, forms…).
- **Organisms** — sections composed of molecules (chat panel, header, floating trigger…).
- **Templates** — the full surface layout with the wiring (`cw-widget-root`).

Every leaf is **presentational**: it receives config via properties and pushes user intent up
through composed `cw:*` custom events. Only the template talks to the store.

<Heading as="h2">Guiding rules</Heading>

1. **Data flows down** — config is always passed as component properties.
2. **Events flow up** — leaves never import or mutate the store.
3. **No `cw:*` side effects in leaves** — everything is delegated to the root.
4. **One source of truth** — `chatStore` owns all widget state.
